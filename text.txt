NestJS Guard'ы выполняются до попадания запроса в обработчик контроллера.
Guard должен понимать:
    Этот маршрут публичный? → пропустить без проверки JWT
    Этот маршрут требует определённых ролей? → проверить роль пользователя

SetMetadata — это встроенная утилита NestJS.
Она прикрепляет произвольные данные к методу или классу через Reflect API
(стандартный механизм TypeScript/JavaScript для метаданных).

Декоратор для ролей
// src/common/decorators/roles.decorator.ts
import { SetMetadata } from '@nestjs/common';
import { Role } from '../enums/role.enum';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: Role[]) => SetMetadata(ROLES_KEY, roles);

 Бизнес-правила
 Проверка дат

 Нельзя создать бронь если:

 startDate >= endDate

 Ошибка:

 400 Bad Request
 Проверка пересечения

 Если номер уже забронирован:

 1 июня - 5 июня

 то нельзя создать:

 2 июня - 4 июня

 или

 4 июня - 10 июня

 или

 30 мая - 2 июня

 Поиск пересечения:

 const exists = await prisma.booking.findFirst({
   where: {

     startDate: {

     endDate: {
       gt: startDate,
     },
   },
 });
